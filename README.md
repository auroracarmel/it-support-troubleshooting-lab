IT Support & Network Troubleshooting Lab

Project Overview

A hands-on portfolio project documenting IT support investigations, Windows troubleshooting, networking diagnostics, and problem-solving techniques.

Objectives

* Practise systematic IT troubleshooting.
* Investigate network connectivity, DNS, and DHCP issues.
* Use Windows command-line tools to collect diagnostic information.
* Document symptoms, evidence, root causes, and resolutions.

Tools

* Windows Command Prompt
* Windows PowerShell
* ipconfig
* ping
* nslookup
* tracert
* Test-NetConnection

Troubleshooting Method

1. Identify the symptoms.
2. Collect evidence.
3. Test possible causes.
4. Identify the likely root cause.
5. Apply an appropriate fix.
6. Retest and document the result.

Investigations

Investigation reports will be added as each scenario is completed and verified.

Learning Outcomes

This project is intended to develop practical IT support, networking, troubleshooting, and technical documentation skills.
